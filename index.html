Why another engine

Six claims, each checkable in the repository — no roadmap promises.

A real JavaScript engine

km-js: a from-scratch lexer → parser → bytecode → VM in pure Rust, with its own DOM arena and mark-sweep collector. It runs unmodified React 18 headless — mount, update, click, text input.

A real render pipeline

HTML parse (km-dom) → CSS cascade (km-css) → block/flex/grid/inline/table layout (km-layout) → box tree (km-render) → CPU paint (km-raster), with fonts (km-font) and images (km-image: PNG, JPEG, GIF, SVG).

Measured, not marketed

Five conformance catalogs with pinned denominators: the WPT rendering, testharness, and remaining-compatibility sets, plus Test262 and the upstream WebAssembly spec suite. Per-row identity comparison — every attempted row is itemized, nothing is averaged away.

Zero native C dependencies

Enforced structurally by CI: no -sys or -dl crates in the product graph, and the linked binaries are ldd-checked. The only dynamic link is glibc — the standard Rust runtime on Linux. TLS is pure-Rust rustls.

Hostile input expected

Single-process by design, so the engine treats every page as adversarial: catch_unwind at untrusted-input seams, panic-family lints denied at compile time, byte- and depth-budgets on untrusted input.

Written in Rust

636,648 lines of Rust across 30 crates.* No V8. No SpiderMonkey. No C in the product graph.

* find crates -name '*.rs' | xargs wc -l | tail -1, counted 2026-10-10 across all 30 workspace crates, including legacy-path crates being superseded.

Questions

What is T.A.B. today?

A browser engine plus its conformance program: parsing, styling, layout, painting, a JavaScript VM, a DOM, and the measurement harness that scores all of it against W3C/whatwg catalogs. It is not a shipping browser — there is no UI product, installer, or release channel.

Can I download it?

No. T.A.B. is unreleased and there are no binaries. This page is a draft of the download page that will exist when there is something to download.

Where is the source?

The engine is developed in a single Rust workspace: github.com/etziolami-ui/Kingmaker — private during development. Public source and binaries are part of the (not yet scheduled) release.

What about the domain?

tab.tools — domain TBD. That name is tentative placeholder branding; nothing is registered or confirmed, and the real address will be announced with the release.

Where do the conformance numbers come from?

From the project’s internal conformance board, which renders both sides of every row and compares them. This site renders a copy of that board’s snapshot (data/conformance.json) with vanilla JavaScript. Suites flagged measured: false in the snapshot are labelled “carried from an earlier run”. No dates, version numbers, sizes, or user counts are invented anywhere on this page.
